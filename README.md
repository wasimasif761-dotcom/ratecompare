# RateCompare 💸
> **"Overseas Pakistanis ka apna Rate App"** — Live Remittance Rates & Zero-Fee Exchange Comparison

RateCompare is a modern, high-performance Progressive Web Application (PWA) built specifically for overseas expatriates in Saudi Arabia, UAE, Kuwait, Qatar, Oman, Bahrain, the UK, and Europe sending hard-earned money home to Pakistan (PKR), India (INR), Bangladesh (BDT), and Egypt (EGP).

---

## 🌟 Key Features

- **⚡ Live Exchange Rates**: Real-time currency exchange rates fetched seamlessly via open mirrors (`jsdelivr / fawazahmed0` and `NemesisX1`) with zero paid API costs.
- **🆓 Zero-Fee Provider Spotlight**: Dedicated tags, neon glow badges, and "Free Transfers Only" filters for 100% free digital remittance apps including **Barq (بارق)**, **UrPay**, **Mobily Pay**, and **Careem Pay**.
- **🧮 Smart Remittance Calculator**: Input any send amount (500, 1000, 2500, 5000+ SAR/AED/KWD) and instantly see exact receiver payout comparisons side-by-side with transfer fees factored in.
- **📱 3-Dot Options Menu**: Clean slide-out drawer providing quick access to:
  - Profile & Settings (Default currencies, PWA management)
  - Dark Mode (Deep Emerald Green + Gold) / Light Mode toggle
  - Multilingual support with native RTL layout
  - One-tap WhatsApp app sharing
  - In-app 5-star user feedback form
  - Developer info & direct WhatsApp support
  - Privacy Policy & Terms of Service
  - Secure developer Admin Panel
- **🌐 5 Native Languages**: Full localization and RTL support for **English**, **Urdu (اردو)**, **Hindi (हिन्दी)**, **Bengali (বাংলা)**, and **Arabic (العربية)**.
- **👥 Community Rate Reporter**: Real users can report local branch/kiosk exchange rates, vote on reports, and view verified crowd-sourced rates.
- **🔔 Threshold Rate Alerts**: Set custom exchange rate triggers to get notified when your target rate is reached.
- **📲 Progressive Web App (PWA)**: Works offline, installable directly to iOS and Android home screens without an app store download.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS (Deep Emerald & Gold Theme)
- **Icons**: Lucide React
- **Build Tool**: Vite 8
- **PWA**: `vite-plugin-pwa` with custom offline cache fallback
- **Data Source**: jsdelivr `@fawazahmed0/currency-api` (Primary) & `NemesisX1` (Fallback)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn or bun

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/ratecompare.git
   cd ratecompare
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
